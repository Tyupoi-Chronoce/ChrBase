# Plans

## 1. can type commands in the debug console to control the process;
- set command buffer size 32 Bytes;;
- `int <Center Index>` can manually trigger an interrupt (pause the operation), and must be manually resumed.
    if without arg `Center Index`, all Centers will be interrupted by default;;
- `resume <Center Index>` can manually resume the operation, cant without arg `Center Index`;;
- `kill <Center Index>` can manually stop the Center process, cant without arg `Center Index`;;
- `quit`/`exit` save logs and exit;;
- `step <Center Index>` the Center will be single-step debugging mode.
    if without arg `Center Index`, all Centers will be single-step debugged by default;;
- `next <Center Index>` the Center will move forward one step if in single-step debugging mode. the Center must in single-step debugging mode.
    if without arg `Center Index`, all Centers in single-step debugging mode will move forward one step by default;;
- `run <Center Index>` the Center will be running mode. if without arg `Center Index`, all Centers will be running by default.
    can quit the single-step debugging mode if was in;;
- `ramData <Center Index> <RAM Address(hex)> <Length(1,2,4)>` can print **unsigned hex data in the RAM tha the Center points to** to the console.
    cant without arg `Center Index` `RAM Address(hex)`. if without arg `Length(1,2,4)`, the length will be 4 bytes by default;;

## 2. can show things on the window by GraphicDev, have mode **GUI** and **CLI**;

## 3. ProcessingCenters can out info to the window;
- in **CLI** mode, Centers out ASCII Bytes to the GBuffer of GraphicDev, and the screen show datas as ASCII characters;
- in **GUI** mode, Centers out RGBA 32b data to the GBuffer of GraphicDev, and the screen show datas as RGBA pixels;
